# API Reference

Generated by hand from `apps/server/src/shared/constants/endpoints.ts`, the routers, and DTOs in `modules/*/dto/`. An OpenAPI spec generated from Zod schemas is planned (plan Phase 4e). Until then, **update this file whenever a route or DTO changes.**

Base path: `/api/v1`. Default local base URL: `http://localhost:3000`.

## Conventions

**Auth legend**

| Tag | Meaning |
|---|---|
| none | Public |
| JWT | `Authorization: Bearer <accessToken>` |
| JWT+P | JWT + project membership check on `projectId` (location in brackets) |
| JWT+O | JWT + **owner** of `projectId` |
| KEY | `x-api-key: proj_…` |
| RUM | `x-rum-key: …` and an allowed `Origin` |

**Success envelope**
```json
{ "data": {}, "meta": { "requestId": "uuid", "timestamp": "2026-11-10T12:00:00.000Z" } }
```

**Error envelope**
```json
{ "error": "VALIDATION_ERROR", "message": "Request validation failed", "requestId": "uuid", "details": {} }
```

| HTTP | `error` | When |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Zod validation failed (`details` = flattened issues) |
| 401 | `UNAUTHORIZED` | Missing/invalid JWT, key, or refresh token; bad credentials |
| 403 | `FORBIDDEN` | Not a project member / not owner / RUM origin not allowed |
| 404 | `NOT_FOUND` | Unknown route, user, key, trace |
| 409 | `CONFLICT` | Email already in use |
| 415 | `UNSUPPORTED_MEDIA_TYPE` | RUM ingest without `application/json` |
| 429 | `RATE_LIMIT_EXCEEDED` | Ingest/RUM rate limit |
| 500 | `INTERNAL_ERROR` | Unhandled error |

The API/RUM key middlewares currently return `{error, message}` **without** `requestId` (KI-23). `requireAuth` accepts **access** tokens only; refresh tokens get 401.

**Common headers**

| Header | Direction | Purpose |
|---|---|---|
| `x-request-id` | in/out | Correlation ID; generated if absent |
| `x-idempotency-key` | in | Dedupe ingest/RUM batches for 5 min (8–128 chars) |

**Timeframes:** `1h`, `6h`, `24h` (default), `7d`, `30d`.

## Auth: `/api/v1/auth`

| Method | Path | Auth | Body / Query | Notes |
|---|---|---|---|---|
| POST | `/login` | none | `{email, password}` | Returns `{accessToken, refreshToken, user}`; sets `refresh_token` cookie |

## Ingest: `/api/v1/ingest`

| Method | Path | Auth | Response |
|---|---|---|---|
| POST | `/` | KEY | `202 {status:"queued", received, batchId}`; `403 FORBIDDEN` if body `projectId` ≠ key's project |

```jsonc
{
  "projectId": "proj_xxxxxxxxxxxxxxxx",   // optional; the key's project is always used. If sent and different → 403
  "sdkVersion": "1.0.0",                   // semver, default 1.0.0
  "logs": [                                // 1–500
    {
      "method": "GET",                     // GET|POST|PUT|DELETE|PATCH|OPTIONS
      "endpoint": "/users/123",            // ≤512; numeric/UUID segments normalised to :id
      "statusCode": 200,                   // 100–599
      "latencyMs": 42,                     // int 0–300000
      "ip": "203.0.113.7",                 // optional, hashed server-side
      "userAgent": "…",                    // optional ≤512
      "timestamp": "2026-11-10T12:00:00Z", // ISO-8601 UTC, required
      "tags": ["checkout"]                 // optional, ≤10 × ≤50 chars
    }
  ]
}
```

## RUM: `/api/v1/rum`

| Method | Path | Auth | Notes |
|---|---|---|---|
| POST | `/` | RUM | `Content-Type: application/json` required; `202` |
| GET | `/overview` | JWT (service checks access) | `?projectId&timeframe&limit` |
| GET | `/series` | JWT | same |
| GET | `/paths` | JWT | same |
| GET | `/devices` | JWT | same |
| GET | `/geo` | JWT | same |
| GET | `/referrers` | JWT | same |

RUM ingest body:

```jsonc
{
  "sdkVersion": "1.0.0",
  "events": [                               // 1–200
    {
      "type": "page_view",                  // page_view | web_vital | heartbeat
      "path": "/pricing",                   // required, ≤1024
      "referrer": "https://google.com",     // optional
      "timestamp": "2026-11-10T12:00:00Z",  // must be within −24h / +5min of server time
      "sessionId": "abc",                   // optional ≤128
      "ttfbMs": 120, "fcpMs": 800, "lcpMs": 1500,   // optional, 0–600000
      "metadata": { "k": "v" }              // optional string|number|boolean values
    }
  ]
}
```

RUM `projectId` query param must match `^proj_[A-Za-z0-9_-]{16,}$`.

## Metrics: `/api/v1/metrics`

|---|---|---|

## WebSocket (Socket.IO)

Connect to the API origin (`NEXT_PUBLIC_WS_URL`).

| Direction | Event | Payload |
|---|---|---|
| client → server | `join` | `{ projectId, token }` (access JWT) |
| server → client | `join:ok` | `{ projectId, userId }` |
| server → client | `join:error` | `{ message }` |
| server → client | `pulse:live` | every 2 s: throughput, error rate, avg latency, top endpoints, latest insight |

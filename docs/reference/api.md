# API Reference

Generated by hand from `apps/server/src/shared/constants/endpoints.ts`, the routers, and DTOs in `modules/*/dto/`. An OpenAPI spec generated from Zod schemas is planned (plan Phase 4e). Until then, **update this file whenever a route or DTO changes.**

Base path: `/api/v1`. Default local base URL: `http://localhost:3000`.

## Conventions

**Auth legend**

| Tag | Meaning |
|---|---|
| none | Public |
| JWT | `Authorization: Bearer <accessToken>` |
| JWT+P | JWT + project membership check on `projectId` (location in brackets) |
| JWT+O | JWT + **owner** of `projectId` |
| KEY | `x-api-key: proj_…` |
| RUM | `x-rum-key: …` and an allowed `Origin` |

**Success envelope**
```json
{ "data": {}, "meta": { "requestId": "uuid", "timestamp": "2026-11-10T12:00:00.000Z" } }
```

**Error envelope**
```json
{ "error": "VALIDATION_ERROR", "message": "Request validation failed", "requestId": "uuid", "details": {} }
```

| HTTP | `error` | When |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Zod validation failed (`details` = flattened issues), or the body is not valid JSON |
| 401 | `UNAUTHORIZED` | Missing/invalid JWT, key, or refresh token; bad credentials |
| 403 | `FORBIDDEN` | Not a project member / not owner / RUM origin not allowed |
| 404 | `NOT_FOUND` | Unknown route, user, key, trace |
| 409 | `CONFLICT` | Email already in use |
| 413 | `PAYLOAD_TOO_LARGE` | JSON body over 2 MB |
| 415 | `UNSUPPORTED_MEDIA_TYPE` | RUM ingest without `application/json`; unsupported body charset |
| 429 | `RATE_LIMIT_EXCEEDED` | Ingest/RUM events-per-minute limit; headers `Retry-After`, `X-RateLimit-Limit`, `X-RateLimit-Remaining` |
| 500 | `INTERNAL_ERROR` | Unhandled error |
| 503 | `SERVICE_UNAVAILABLE` | Temporary: the batch couldn't be queued, an API/RUM key couldn't be checked (database or Redis unreachable), or billing isn't configured. Ingest responses carry `Retry-After`; retry with the same `x-idempotency-key` |

API/RUM key errors use the same envelope. A wrong key is `401` (don't retry); a key check that couldn't run is `503` (retry). `requireAuth` accepts **access** tokens only; refresh tokens get 401.

**Common headers**

| Header | Direction | Purpose |
|---|---|---|
| `x-request-id` | in/out | Correlation ID; generated if absent |
| `x-idempotency-key` | in | Dedupe ingest/RUM batches for 5 min (8–128 chars) |

**Timeframes:** `1h`, `6h`, `24h` (default), `7d`, `30d`.

## Auth: `/api/v1/auth`

| Method | Path | Auth | Body / Query | Notes |
|---|---|---|---|---|
| POST | `/login` | none | `{email, password}` | Returns `{accessToken, refreshToken, user}`; sets `refresh_token` cookie |
| POST | `/refresh` | cookie or body | `{refreshToken?}` | Rotates the pair and the cookie. A body token wins; using only the cookie requires the `X-Requested-With` header (`403` otherwise) |
| POST | `/logout` | none | n/a | Clears cookie |
| GET | `/oauth/:provider/start` | none | `?mode=login\|register` | `provider` = `google` \| `github`; 302 to provider |
| GET | `/oauth/:provider/callback` | none | provider params | 302 to `${FRONTEND_URL}/oauth/callback?code&provider`; `code` is single-use and valid for 60 s |
| POST | `/oauth/exchange` | none | `{code}` | Swaps the callback `code` for `{accessToken, refreshToken}` and sets the `refresh_token` cookie. 400 malformed, 401 unknown/expired/used |
| POST | `/keys` | JWT+O [body] | `{projectId, label?}` | Legacy ingest key issuance (prefer `POST /keys`) |
| POST | `/rum-keys` | JWT+O [body] | `{projectId, label?, allowedOrigins?}` | RUM key issuance |

## Ingest: `/api/v1/ingest`

| Method | Path | Auth | Response |
|---|---|---|---|
| POST | `/` | KEY | `202 {status:"queued", received, batchId}` once RabbitMQ has confirmed the batch; `503 SERVICE_UNAVAILABLE` + `Retry-After: 5` if it couldn't be queued (retry, same `x-idempotency-key` is safe); `403 FORBIDDEN` if body `projectId` ≠ key's project |

```jsonc
{
  "projectId": "proj_xxxxxxxxxxxxxxxx",   // optional; the key's project is always used. If sent and different → 403
  "sdkVersion": "1.0.0",                   // semver, default 1.0.0
  "logs": [                                // 1–500
    {
      "method": "GET",                     // GET|POST|PUT|DELETE|PATCH|OPTIONS
      "endpoint": "/users/123",            // ≤512; numeric/UUID segments normalised to :id
      "statusCode": 200,                   // 100–599
      "latencyMs": 42,                     // int 0–300000
      "ip": "203.0.113.7",                 // optional, hashed server-side
      "userAgent": "…",                    // optional ≤512
      "timestamp": "2026-11-10T12:00:00Z", // ISO-8601 UTC, required
      "tags": ["checkout"]                 // optional, ≤10 × ≤50 chars
    }
  ]
}
```

RUM ingest body:

```jsonc
{
  "sdkVersion": "1.0.0",
  "events": [                               // 1–200
    {
      "type": "page_view",                  // page_view | web_vital | heartbeat
      "path": "/pricing",                   // required, ≤1024
      "referrer": "https://google.com",     // optional
      "timestamp": "2026-11-10T12:00:00Z",  // must be within −24h / +5min of server time
      "sessionId": "abc",                   // optional ≤128
      "ttfbMs": 120, "fcpMs": 800, "lcpMs": 1500,   // optional, 0–600000
      "metadata": { "k": "v" }              // optional string|number|boolean values
    }
  ]
}
```

RUM `projectId` query param must match `^proj_[A-Za-z0-9_-]{16,}$`.

## Alerts: `/api/v1/alerts`

Reads need project membership; writes need the **owner** role (rules send data to external URLs).

| Method | Path | Auth | Body / Query | Notes |
|---|---|---|---|---|
| GET | `/rules` | JWT+P [query] | `?projectId` | `{projectId, rules[]}` |
| POST | `/rules` | JWT+O [body] | `{projectId, name, conditionType, threshold, windowMinutes?, endpointFilter?, notifyWebhook?, notifyEmail?, isActive?}` | `201 {rule}` |
| PATCH | `/rules/:ruleId` | JWT+O [query] | `?projectId`; any subset of the create fields except `projectId` | `200 {rule}`; `404` if not in this project |
| DELETE | `/rules/:ruleId` | JWT+O [query] | `?projectId` | `204`; `404` if not in this project |
| GET | `/events` | JWT+P [query] | `?projectId&ruleId?&limit?` (1–200, default 50) | `{projectId, events[]}`, newest first |

Rule fields:

- `conditionType`: `error_rate_high` (threshold = percent, 0–100, errors are status ≥ 400) or `latency_p99_high` (threshold = ms).
- `windowMinutes`: 1–1440, default 5. Evaluated over raw logs whose `timestamp` falls in the last N minutes.
- `endpointFilter`: a normalised endpoint such as `/orders/:id`.
- `notifyWebhook`: must be `https://` to a public host. It receives `{text, source, status: "triggered" | "resolved", rule: {id, name, condition, threshold, windowMinutes}, projectId, value}`.
- `notifyEmail`: stored but not sent yet.

Response fields add `state` (`ok` | `firing`), `lastValue`, `lastEvaluatedAt`, `lastTriggeredAt`, `lastResolvedAt`, `createdAt` and `updatedAt`.

Events are `{id, ruleId, ruleName, kind: "triggered" | "resolved", message, value, at}`.

## WebSocket (Socket.IO)

Connect to the API origin (`NEXT_PUBLIC_WS_URL`).

| Direction | Event | Payload |
|---|---|---|
| client → server | `join` | `{ projectId, token }` (access JWT) |
| server → client | `join:ok` | `{ projectId, userId }` |
| server → client | `join:error` | `{ message }` |
| server → client | `pulse:live` | every 2 s: throughput, error rate, avg latency, top endpoints, latest insight |
